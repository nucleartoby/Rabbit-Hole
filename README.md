# Rabbit Hole

Want to know more about something? Go down the rabbit hole...

Enter a word and it lands at the centre of a canvas with everywhere it leads
fanned out around it. Click any of those and *its* connections branch off in
turn, so the shape of what you explored stays on screen as you go.

Content comes from Wikipedia; responses are cached locally so revisiting a
branch is instant.
